# React Todo App

Add, edit, delete and filter tasks. Built to teach state, props and event handling.

## Run it
    npm install
    npm run dev

Open the URL Vite prints (usually http://localhost:5173).

## Where to look
- `src/App.jsx`: state (`useState`), handlers, derived data
- `src/components/TodoItem.jsx`: props in, local state for editing, event handlers
- `src/components/FilterBar.jsx`: a purely props-driven component

`standalone.html` is a no-build version you can open directly in a browser.
